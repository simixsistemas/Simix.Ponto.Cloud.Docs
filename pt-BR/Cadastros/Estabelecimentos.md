# Estabelecimentos

### Código do estabelecimento
Código designado para este novo estabelecimento.

### Nome
Nome que o estabelecimento aparecerá no sistema e no comprovante de registro emitido pelo equipamento, por padrão utilizado a Razão Social da empresa.  

### Endereço
Endereço do estabelecimento, essa informação aparece no comprovante de registro emitido pelo relógio ponto e utilizado para a georestrição de registo pelo app.

### CNPJ
Campo para adicionar o CNPJ da empresa, essa informação aparece no comprovante de registro emitido pelo relógio ponto.  

### Código da cidade
Vincula uma cidade ao estabelecimento. Cidades podem ser cadastradas em Cadastros – Cidades 

### Código do horário padrão para o cadastro de funcionários
Define um quadro de horários padrão para o estabelecimento.

### Código do grupo de ações padrão para o cadastro de funcionários
Define um grupo de para o estabelecimento. 

### Código na folha de pagamento
Preencher com a informação de código da folha de pagamento da empresa junto a contabilidade. Para exportar os dados mensais para a contabilidade através do comando de exportação para folha é necessário que esse campo esteja preenchido.

### Email
Campo para preenchimento com e-mail dos responsáveis da empresa. Opcional. 

### Telefone
Campo para o telefone dos responsáveis do ponto. Opcional.

### Data da instalação
Data de criação do cadastro de estabelecimento. 

### Código do funcionário inicial
Define um range de código de funcionários para serem atribuídos ao estabelecimento, iniciando por este inserido. 

### Código do funcionário final
Define um range de código de funcionários para serem atribuídos ao estabelecimento, finalizando por este inserido. 

### Ativo?
Marcar o estabelecimento como ativo ou inativo no sistema.  

### CEI
Cadastros Específico do INSS, campo opcional sem obrigatoriedade de preenchimento. Atualmente em transição pelo CNO (Cadastro Nacional de Obras). 

### Responsável
Campo para preencher com o nome do responsável. Normalmente deixado em branco pois o nome preenchido aqui é o que aparecerá no lugar de “Responsável” para assinatura na emissão do cartão de espelho do cartão ponto.

### Código do grupo
Pode vincular diferentes estabelecimentos em um mesmo grupo para facilitar no agrupamento e filtro de informações.

### CPF
Preencher com o CPF de um dos responsáveis da empresa. Para alguns modelos de relógio conseguirem concluir a sincronização via rede com sucesso é preciso o preenchimento com um IP válido. Relógios Control ID não precisam de um CPF válido porém é obrigatório que esse campo esteja preenchido para que ocorra a sincronização. 

### Endereço IP
Pode vincular o IP externo da empresa ou informação semelhante.

### Dia de inicio alternativo do cartão
Definir um dia para inicio do período contábil diferente do que está configurado no menu de configuração do sistema.

### Configuração de banco de horas
Caso o estabelecimento tenha configurações diferentes de banco de horas entre estabelecimentos.

### Sigla
Sigla para uso em cálculos do sistema, não é obrigatório preenchimento. 

### Código Externo
Código externo para o estabelecimento. Campo opcional.

### Observacções
Observação que deseja inserir neste cadastro.

### Código conveção coletiva
Informação sobre as convenções coletivas que o estabelecimento segue.
